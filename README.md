# Desktop 3-Column Organizer & Jamo Fixer (Windows)

바탕화면 아이콘을 3열 세로로 공백 없이 깔끔하게 자동 정렬하고, OneDrive 및 윈도우 환경에서 발생하는 한글 자모 분리 현상을 실시간으로 해결해 주는 올인원 자동화 도구입니다.

---

## 📁 파일 구성 (딱 2개의 실행 파일)

1. **`DesktopOrganizer_Start.bat`** (모든 기능 통합 실행기)
   - **자모 분리 해결**: 바탕화면 및 OneDrive 다운로드 폴더의 자모 분리(NFD) 파일명을 완성형(NFC)으로 자동 복원
   - **바탕화면 3열 세로 정렬**: 휴지통 $\rightarrow$ 다운로드(바로가기) $\rightarrow$ 폴더 $\rightarrow$ 일반 파일 순으로 3개 열에 빈틈없이 세로 정렬
   - **시작프로그램 자동 등록**: 윈도우 부팅 시 검은 창 없이 백그라운드에서 조용히 자동 실행되도록 등록
   - **실시간 자동 정렬 데몬**: 파일 추가/삭제 발생 시 2초 디바운싱 후 스스로 재정렬

2. **`DesktopOrganizer_Stop.bat`** (정리 및 자동화 해제기)
   - 백그라운드에서 실행 중인 실시간 감시 프로세스 종료
   - 윈도우 시작프로그램 등록 해제

---

## 🚀 사용 방법

- **시작 / 즉시 정렬**: `DesktopOrganizer_Start.bat` 파일을 더블 클릭하여 실행합니다.
- **해제 / 자동화 종료**: `DesktopOrganizer_Stop.bat` 파일을 더블 클릭하여 실행합니다.

---

## 🛡️ 안정성 및 특징

- **100% 영문 코드 베이스**: Windows CMD/BAT 환경에서 한글 인코딩(CP949 vs UTF-8) 충돌이나 구문 오류가 전혀 발생하지 않도록 코드가 순수 영문(ASCII) 기반으로 설계되었습니다.
- **안전한 2단계 이름 변경**: NTFS 파일시스템의 유니코드 중복 에러를 방지하기 위해 임시 식별자를 거쳐 안전하게 이름을 변경합니다.
- **단독 실행(Self-contained)**: 외부 라이브러리나 추가 스크립트 설치 없이 윈도우 기본 PowerShell과 Win32 API만으로 작동합니다.
